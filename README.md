
Ghost Protocol is a browser mystery game. Search a fictional computer for clues, see how the desktop reacts to your investigation, and save what you find to build a case.

Explore **Files**, **Messages**, and **Calendar**. Start with `last-note.txt` and follow the trail. You can save clues in the Evidence app.

Run locally

```bash
npm install
npm run dev
```

This is just the basic build or the short skeleton of the bigger image. Just to show the process there's a simple UI. More updates to come
